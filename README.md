# Projeto de IAC
O objetivo do projeto foi desenvolver, em assembly RISC-V, um programa que, dado um
conjunto inicial de pontos num espaço bidimensional (2D), identifica 𝑘 grupos de pontos,
tendo em conta a proximidade relativa dos pontos de cada grupo. Para tal, foi
implementado o algoritmo iterativo k-means.

Avaliacao: 7/8
